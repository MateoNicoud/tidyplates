# Reimplement ideas from reference addons, never paste their code

ThreatPlates and Plater Nameplates already run on WoW Forever and guide how we port Tidy Plates, but neither repository has a license file, so their code is all rights reserved by default. Tidy Plates is MIT. We read them for the approach and write our own implementation. Copying a file verbatim needs an explicit license grant first, recorded in a new ADR.
