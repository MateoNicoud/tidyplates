# Target WoW Forever only

This fork drops the retail 8.0 client (`Interface: 80000`) and targets WoW Forever (Interface 16001, `WOW_PROJECT_CAMELOT`). Deprecated APIs are replaced directly instead of being branched by client flavour, which keeps the code simple. The upstream project has not been updated in eight years, so a merge back is not a goal, and keeping retail compatibility would add cost for no benefit.
